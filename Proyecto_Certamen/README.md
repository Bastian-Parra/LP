# Simulador de Máquina de Turing - Certamen 1

Intérprete para Máquinas de Turing desarrollado en TypeScript, utilizando ANTLR4 para el análisis léxico y sintáctico.

## Requisitos Previos
- Node.js (v18+)
- Java (JRE 11+) (Requerido por ANTLR para compilar la gramática)
